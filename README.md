# hermes-dlc

Дополнение для [Hermes Agent](https://github.com/NousResearch/hermes-agent): планирование задач,
самосовершенствующаяся библиотека агентов-специалистов, Kanban, память Honcho на локальных
эмбеддингах, локальный RAG.

**Основной документ: [docs/SPEC.md](docs/SPEC.md)** — спецификация (требования, архитектура,
GUI, алгоритмы, критерии приёмки, этапы).

## Содержимое

| Путь | Статус |
|---|---|
| `docs/SPEC.md` | Спецификация v0.2, на согласовании |
| `dlc/` | Черновой прототип агентской части (инструменты, хуки, навыки). Будет приведён к структуре пакета из SPEC §4.1 после согласования. |
| `infra/honcho/` | Справочные значения `.env` для self-hosted Honcho с EmbeddingGemma (SPEC §7.2). Применяются вручную. |
| `tests/` | Тесты прототипа (`python -m pytest`) |

Установочных скриптов нет: установка и настройка выполняются вручную через GUI (SPEC §0.1, §4.1, §7).
